# PasswordSmith

PasswordSmith is a React Native app for generating deterministic passwords from a secret and service name.

## V1

The first version includes:

- Password length input
- Secret input
- Service input
- Lowercase, uppercase, numbers, and symbols
- Deterministic password generation
- Password strength indicator
- Copy-to-clipboard functionality
- Basic input validation

## Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Expo Clipboard
- Android / Gradle

## Development

Install dependencies:

```bash
npm install
```

Start the dev server

```bash
npx expo start
```

For web preview:

```bash
npx expo start --web
```
